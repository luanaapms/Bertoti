# INTERAÇÃO HUMANO COMPUTADOR 

## Como era a Interação Humano Computador nos anos 70? (CLI)
CLI significa Interface de Linha de Comando, um programa que permite que os usuários digitem comandos de texto dando instruções a um computador para fazer funções específicas. Na época, a forma de interação entre o usuário e o computador era por um terminal de texto, onde digitavam comandos diretamente no prompt de comando para realizar qualquer ação, geralmente para sistemas operacionais como o MS-DOS ou UNIX. Os terminais eram monitores monocromáticos, e não possuiam interface gráfica, exigindo conhecimento avançado. Utilizar o CLI, também traz pontos positivos como necessitar de menos recursos e maior precisão. <br> <br>

## E dos 80 até 2007? (GUI)
 Já o GUI ou Interface Gráfica do Usuário, é uma forma de interação com o computador baseada em elementos visuais, como janelas, ícones e botões, em vez de apenas texto e comandos. Os anos de 80 e 90 marcaram o domínio das GUI, tornando os computadores acessíveis para o público geral, com os principais avanços do Microsoft Windows 95 introduzindo o Menu Iniciar e a Barra de Tarefas, o Mac OS System 7 com suporte a cores e multitarefa, o Linux com ambiente gráfico, e Navegadores Web (Mosaic, Netscape Navigator, Internet Explorer). Nos anos 2000 evoluiu para se tornar mais intuitiva, dinâmica e visualmente atraente, com a popularização dos laptops e era dos smartphones, integração com a Internet e design acessível. <br> <br>

## E de 2007 até agora? (NUI)
A Interface Natural do Usuário, permite a interação com o computador de forma mais intuitiva e natural, utilizando gestos, toque, voz, ou até mesmo movimentos corporais. Entre as características, temos o Reconhecimento de voz, permitindo controlar o dispositivo ou fazer comandos verbais (Siri, Alexa), Touchscreens(Iphone), e dispositivos de realidade virtual (VR) e realidade aumentada (AR). A ideia é criar uma experiência mais fluida, sem a necessidade de aprender comandos complexos ou usar dispositivos específicos como o mouse. <br> <br>

## Qual o futuro da IHC?
O futuro da Interação Humano-Computador está caminhando para uma integração ainda mais profunda entre tecnologia e a vida cotidiana. O uso de IA será fundamental para criar interfaces mais inteligentes e adaptativas, que se ajustam de forma proativa ao comportamento do usuário. Quem sabe no futuro, podemos ser capazes de controlar aparelhos e navegar por interfaces digitais diretamente com os pensamentos, uma experiência de interação extremamente natural e eficiente.
