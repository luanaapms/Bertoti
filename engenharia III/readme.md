# ENGENHARIA DE SOFTWARE III

## O que é Padrão de Projetos?
Padrões de projeto são soluções reutilizáveis e comprovadas para problemas recorrentes no desenvolvimento de software. Eles descrevem abordagens testadas para organizar o código e resolver desafios de design de forma eficiente, seguindo princípios de programação orientada a objetos. Não são códigos prontos, mas sim modelos que podem ser adaptados a diferentes contextos, ajudando a criar sistemas mais flexíveis, manuteníveis e de fácil compreensão.
