## O que é padrão de projetos MVC?
O MVC (Model-View-Controller) é um padrão de arquitetura de software que organiza uma aplicação em três camadas principais, separando suas responsabilidades e tornando o código mais limpo e fácil de manter. <br>
- Model (Modelo): Representa os dados e as regras de negócio da aplicação. É responsável por gerenciar as informações, acessar o banco de dados e aplicar a lógica central do sistema. <br>
- View (Visão): É responsável pela interface com o usuário, exibindo os dados e capturando as interações (entradas e saídas). <br>
- Controller (Controlador): Atua como intermediário entre o Model e a View, processando as ações do usuário, atualizando os dados e definindo o que deve ser mostrado na interface.
