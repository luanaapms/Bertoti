## O que é padrão de projetos OBSERVER?
O Observer é um padrão de projeto comportamental que estabelece um mecanismo de assinatura, permitindo que múltiplos objetos sejam automaticamente notificados sobre eventos que ocorrem em um objeto observado. Em essência, ele sugere que a classe publicadora disponibilize um sistema de inscrição, no qual objetos interessados possam assinar ou cancelar a assinatura de uma corrente de eventos emitidos pela publicadora.

## Qual é o anti-padrão do OBSERVER?
O antipadrão nesse contexto ocorre quando há alto acoplamento, ou seja, uma forte dependência entre diferentes partes (ou módulos) do sistema. Em sistemas altamente acoplados, uma alteração em um módulo pode gerar efeitos colaterais indesejados em outros, já que estão excessivamente interligados. Esse problema surge especialmente quando o publisher é implementado para depender diretamente de uma classe concreta, em vez de abstrações. O uso de polimorfismo é justamente o que permite o desacoplamento: ao depender de interfaces ou classes abstratas, o publisher consegue notificar diferentes subscribers sem conhecer suas implementações específicas, mantendo o sistema flexível, extensível e de fácil manutenção.
